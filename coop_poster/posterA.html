Challenges & How I Overcame Them

Steep Learning Curve

Many new tools in a few weeks (Jena, SPARQL, RAG, Ollama).
→ Read the docs, built small tests and asked questions early.

Reproducing a Handed-Over System

Environment errors, version mismatches and machine-specific paths.
→ Issue log, portable paths, pinned versions and a frozen Git baseline.

Unsupported or Unsafe Answers

Baseline review flagged 12/50 hallucinations; knee bending triggered false emergency alerts.
→ Strengthened the safety prompt, added an “insufficient evidence” fallback and re-ran every failed case.

Biggest Takeaways
My co-op taught me that good AI is not only about accuracy — it is about evidence, safety and honesty. I leave KACST more confident, more independent and ready for a career in data and AI.
Advice for future co-op students: ask early, document everything, and back every result with evidence.
